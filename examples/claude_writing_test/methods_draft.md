# Methods

## Differential Expression Analysis

Differential expression analysis was performed to identify genes with altered expression between tumor and normal samples. The analysis was conducted using the edgeR package in R. Genes meeting the differential expression criteria were retained for subsequent prognostic screening.

## Univariate Cox Regression Analysis

To evaluate the prognostic significance of the differentially expressed genes, univariate Cox regression analysis was performed using survival analysis methods in R. Each gene was individually assessed for its association with patient survival outcomes. Genes demonstrating significant associations with prognosis were identified as candidate prognostic biomarkers for further investigation.
